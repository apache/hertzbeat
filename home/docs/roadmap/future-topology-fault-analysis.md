This is a **proposed direction**, not an available feature or a delivery commitment. No release date is assigned.

## Operator problem

Operators need to know whether a displayed dependency is observed, registered or merely inferred.

## Current alpha boundary

Entities can expose existing relation previews and related evidence. A graph edge or correlated error is not proof of causation or complete dependency discovery. See the [current operator guide](../help/service_observability.md).

## Proposed capability

Explore evidence-backed dependency inspection with explicit time, source and uncertainty.

## Evidence required

Use real graph data to verify pan/zoom, selection, stale edges, absent evidence and return navigation without resetting the operator viewport.

## Non-goals

No complete inferred graph, automatic root-cause verdict or scale claim from mock nodes.

## Contribution entry

Bring a concrete workflow and a reproducible failure to the [contribution process](../community/contribution.md). Agree the smallest contract and acceptance evidence before implementation. [Return to the roadmap](./index.md).
