## How a direction becomes a release commitment

A maintainer must agree the operator problem, source/API ownership, smallest implementation and executable acceptance scenarios. Missing data, permissions, cancellation, compatibility and native backup/restart behavior remain explicit gates. Local developer results do not establish scale, GA or an SLO.

The [external directory reference](./datadog-directory-map.md) helps organize questions; it does not set product scope automatically. Follow the [contribution process](../community/contribution.md) with a bounded proposal.
