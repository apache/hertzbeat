This is a **proposed direction**, not an available feature or a delivery commitment. No release date is assigned.

## Operator problem

A service investigation should expose a reliable owner and source reference when those records exist.

## Current alpha boundary

The Services page uses service entities and existing associations. It does not supply a complete repository, team or deployment catalog. See the [current operator guide](../help/service_observability.md).

## Proposed capability

Consider optional repository, ownership and deployment references with visible source and update time.

## Evidence required

Start with one read-only integration and prove missing ownership, stale references, permission failures and safe navigation.

## Non-goals

No mandatory second catalog, automatic ownership inference or write access to repositories.

## Contribution entry

Bring a concrete workflow and a reproducible failure to the [contribution process](../community/contribution.md). Agree the smallest contract and acceptance evidence before implementation. [Return to the roadmap](./index.md).
