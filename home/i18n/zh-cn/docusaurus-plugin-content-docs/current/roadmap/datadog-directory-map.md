## 开源私有部署说明

名称类似的领域可能需要不同的数据模型、权限边界和运行预算。HertzBeat alpha 仍是依赖已说明存储和工具的私有部署应用；此目录不授权创建外部云资源，也不引入第二套权限系统。资源身份和拓扑仍是[分别讨论](./future-resource-catalog.md)的[候选问题](./future-topology-fault-analysis.md)。

请从[路线图首页](./index.md)阅读各方向的非目标与所需证据。当前功能由操作手册说明，不能从其他产品的导航推断。
