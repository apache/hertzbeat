本页是**候选方向**，不代表功能已提供，也不构成交付承诺；目前没有发布日期。

## 运维问题

开发者需要在将应用故障交给运维人员时保持稳定的调查上下文。

## 当前 alpha 边界

OTel 应用指南、受控 API 和固定时间窗调查链接是当前入口。外部 MCP 兼容和任意插件市场不属于 alpha 承诺。 参见[当前操作指南](../help/explore_saved_queries.md)。

## 候选能力

研究一个有文档的只读开发者集成，携带服务身份、时间和来源引用。

## 所需证据

验证无效链接、会话过期、身份缺失、路由兼容和取消，同时不丢弃原查询语义。

## 非目标

不承诺所有 IDE 等价，不执行远程 shell，也不进行未说明的凭据传递。

## 贡献入口

请通过[贡献流程](../community/contribution.md)提供具体工作流和可复现失败，再约定最小契约与验收证据。[返回路线图](./index.md)。
