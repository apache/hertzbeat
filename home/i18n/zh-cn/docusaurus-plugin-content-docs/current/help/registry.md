> 采集并监控注册中心的通用性能指标。

**协议：registry**

## 监控微服务

1. 确保您的**注册中心**可用。

   > 当前支持 `Consul` 和 `Nacos`。

2. 在 HertzBeat 中新增 http_sd 监控，并填写**注册中心**的必要信息，例如主机、端口等。
3. 点击**确定**。

## 配置参数

| 参数名称 | 参数帮助说明 |
|----------|--------------|
| 主机 | 被监控的 IPV4、IPV6 地址或域名。注意⚠️不要填写协议头（例如：`https://`、`http://`）。 |
| 任务名称 | 用于标识此次监控的名称，名称需要保持唯一。 |
| 端口 | 注册中心提供的端口。 |
| 服务发现客户端类型 | 选择需要监控的注册中心。 |
| 采集间隔 | 定期采集监控数据的时间间隔，单位：秒，最小可设置为 30 秒。 |
| 是否探测 | 在添加监控前探测并检查监控可用性。只有探测成功后，才会继续添加和修改操作。 |
| 描述备注 | 用于补充标识和描述此次监控的信息，用户可以在此填写备注。 |
