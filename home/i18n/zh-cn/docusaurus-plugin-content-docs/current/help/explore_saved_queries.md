打开 **Explore**（`/explore`）查询指标、日志或链路。工作台保持连续流程：选择信号、编辑查询条件、点击 **查询**、查看结果。控件中的待应用修改不会静默替换当前调查。

## 查询与证据下钻

将信号支持的过滤条件与服务、命名空间、环境和时间组合使用。指标需要实际存储的指标名称；日志支持搜索、级别和关联字段；链路支持操作、错误、span 范围和延迟条件。沿链路或相关日志下钻时保留原绝对时间窗，使证据对应同一次调查。

链路列表的 **最新优先** 和 **根链路耗时最长优先** 会请求服务器先排序、再分页。只有完整已观测链路能够识别唯一根 span 时才有根耗时。缺根或多根不会用子 span 耗时或观测跨度来替代。

查看数据行时同时阅读覆盖提示。完整时间窗、受限候选集、结果截断和覆盖未知是不同状态。旧响应没有覆盖元数据时保持未知。迟到 span 会改变页面结果，列表不承诺快照隔离。

空结果表示当前已应用查询没有返回匹配行。存储不可用、权限错误、无效下钻上下文或请求失败会分别显示。无效的显式时间窗必须修正后才能查询，不会被静默替换为更宽的默认范围。

## 保存已应用的查询

1. 设置条件并点击 **查询**。
2. 选择 **保存查询**，填写名称和可选说明，再保存。
3. 从 Explore 或开始页进入 **已保存查询**，找到记录。
4. 选择 **打开查询**，用保存的条件完整替换当前查询；若有尚未应用的本地修改，需要决定是否丢弃。

保存使用 **已应用** 的条件。修改条件后未执行查询时，保存、更新和另存为会禁用，并提示先查询。取消名称和说明弹窗不执行写入。写入失败会保留输入；同一新建或副本弹窗重试时复用原记录键。

保存查询由当前 HertzBeat 安装实例共享。管理员和有写权限的用户可以修改或删除共享记录，访客账户可以读取。它们不是按用户隔离的私人书签。

## 相对与绝对时间

| 模式 | 重新打开时的行为 |
|---|---|
| 相对预设 | 根据当前时间重新计算范围；支持的自动刷新或实时设置仍属于查询条件 |
| 绝对调查 | 恢复精确的开始、结束和时区，不随当前时钟前移 |

重新打开会从第一页结果开始。导航历史和返回目的地不是共享查询条件。重新打开当前已选中的同一记录，也会恢复其保存条件，而不是保留旧本地草稿。聚焦 Trace 和 Log 调查同样提供保存查询操作。

## 更新、另存为与删除

打开记录后，修改条件并点击 **查询**，再用 **更新保存查询** 替换原记录。**另存为** 使用新键创建另一条共享记录。取消任一弹窗不会修改记录。删除操作在确认后移除选中的共享资产。

保存查询没有仪表盘那样的版本冲突保护，并发编辑共享记录时需要协调。有写权限的角色作用于整个安装实例的共享记录。离开页面或失去写权限会使旧的本地完成回调失效，但不会撤销服务器已经接受的写入。

## 旧记录与不支持的记录

打开记录是只读操作。只有能够不丢失字段、准确恢复查询含义的已知旧路由才会转换；旧记录仅在显式更新后写为当前格式。未知版本、格式错误的载荷、未知参数或歧义时间／身份组合不能打开或覆盖。

使用 **查看原始记录** 和 **导出原始 JSON** 保留诊断所需的原文。导出不代表已恢复一个不受支持的查询。例如，旧 PostgreSQL 大对象引用导出后的数字载荷仍只是引用，不是原查询文本。存储兼容说明见 [升级指南](../start/upgrade.md)。

## 存储格式与限制

当前载荷只有一个查询权威来源：`{ "version": 1, "query": { ... } }`。DTO 路由是信号判别入口 `/explore?signal=metrics`、`/explore?signal=logs` 或 `/explore?signal=traces`。可选查询摘要仅用于展示，不是恢复失败时的备用来源。

载荷保留支持的查询条件及相对／绝对时间模式，不保存结果页码、当前保存记录键，以及 Services、Dashboard 或 Explore 返回链接。序列化载荷最多 65,535 个 UTF-8 字节，多字节字符会占用多个字节。后端对可选查询摘要使用相同字节上限；名称和说明保留独立字符限制。

对于受限面板合同支持的已应用查询，可使用 [添加到仪表盘](./perses_dashboard.md)。仪表盘转换支持的字段集合小于保存查询，不能保留的条件会被明确拒绝。
